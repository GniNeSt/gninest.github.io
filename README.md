# Gninest · Game Client Portfolio

정효준(Gninest)의 게임 클라이언트 프로그래머 포트폴리오 사이트입니다.
Unity/C#과 C++/DirectX 9·WinAPI로 완성한 게임과 공모전 입상작을 소개합니다.

- 사이트: GitHub Pages 주소 (Settings → Pages에서 확인)
- 구성: `index.html` · `style.css` · `portfolio.js`(작품 데이터) · `assets/`(플레이 장면·증빙 이미지)

모작(별의 커비, 메탈슬러그, Delver)의 원작 리소스와 외부 에셋 저작권은 각 원저작자에게 있습니다.
